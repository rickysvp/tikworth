# 商业价值分析系统重构方案

## 摘要

当前分析系统对各类账号的商业价值评估缺乏可信度，头部账号估值严重偏低，评级逻辑与商业价值脱节。用户反馈"所有分析都很离谱，完全没有商业价值"。

本方案采用**混合分层法**：底层用市场对标保证数据可信度，上层用专家推理链输出可读的专业分析。目标：让品牌方、创作者、MCN 机构三类用户都愿意付费，并觉得分析可靠。

## 目标用户与核心价值

| 用户群 | 核心需求 | 为什么付费 |
|--------|----------|-----------|
| 品牌方/广告主 | 评估网红真实商业价值，判断 ROI | 避免投到假号，获取精准报价参考 |
| 创作者/网红 | 了解自己账号值多少钱，如何提升 | 报价有底气，知道增长方向 |
| MCN/经纪机构 | 批量评估签约/竞品账号 | 专业决策依据，提升签约效率 |

**三层价值体系**：市场情报（对标数据） + 增长策略（可落地方向） + 风险控制（避坑预警）

## 整体架构

```
TikTok 原始数据
    │
    ▼
┌─────────────────────────────────────┐
│  1. 数据清洗 & 分类（保留现有）       │
│  - 视频成熟度分层                    │
│  - 账号类型识别                      │
│  - 地区/赛道标注                     │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  2. 市场基准对标（新增）             │
│  - 同 tier × 同赛道 × 同地区         │
│  - 百分位排名（非绝对分数）           │
│  - 市场行情区间（P25-P50-P75）       │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  3. 专家因子调整（增强）             │
│  - 风险折损（量化百分比）             │
│  - 增长溢价（三情景）                │
│  - 品牌/IP 溢价                     │
│  - 认证/地区加成                     │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  4. 分层输出                        │
│  L1: 估值概要 + 市场对标（免费）      │
│  L2: 诊断结论 + 同侪对比（免费）      │
│  L3: 收入预测 + 增长路线（付费）      │
│  L4: 深度分析 + 风险矩阵（付费）      │
└─────────────────────────────────────┘
```

核心变化：
- 新增第 2 步"市场基准对标"：所有评分/估值不再孤立计算
- 每个数字都带"置信依据"：公式计算 → 市场校准 → 专家调整 → 输出
- 输出结构 L1-L4 不变，但每层内容升级

## 10 维评分体系

### 三层结构

**第一层：核心驱动（60% 权重，决定评级上限）**

| 维度 | 权重 | 衡量内容 |
|------|------|----------|
| 规模价值 | 20% | 真实粉丝数（扣除僵尸粉估算） |
| 赛道溢价 | 20% | 品类 CPM × 地区系数 |
| 变现能力 | 20% | 已开通变现渠道数 + 收入稳定性 |

**第二层：质量调节（30% 权重，决定同级内排名）**

| 维度 | 权重 | 衡量内容 |
|------|------|----------|
| 互动质量 | 10% | 真实互动率 vs 同赛道基准 + 评论深度 |
| 内容质量 | 8% | 播放稳定性(CV) + 爆款率 + 垂直度 |
| 粉丝真实度 | 7% | 粉关比 + 互动一致性 |
| 增长势能 | 5% | 30天/60天播放变化率 |

**第三层：风险调节（10% 权重，只扣分不加分，触发直接降级）**

| 维度 | 衡量内容 |
|------|----------|
| 账号健康 | 限流/违规/断更风险 |
| 流量稳定 | 成熟视频 CV 值 |
| 商业信号 | 带货/品牌合作意图检测 |

### 评分流程

```
第一步：核心驱动 → 确定评级区间
  规模+赛道+变现 高 → S/A 区间
  规模+赛道+变现 中 → B/C 区间
  规模+赛道+变现 低 → D/E 区间

第二步：质量调节 → 区间内微调
  互动+内容+真实度+增长 高 → 向上一档
  互动+内容+真实度+增长 低 → 向下一档

第三步：风险调节 → 降级/否决
  有高风险信号 → 强制降一档
  有严重风险信号 → 直接 F 级
```

## 评级系统

### 评级定义（全量排名，非同级对比）

| 等级 | 条件 |
|------|------|
| S | top 1%：商业价值 > $100万，或 粉丝 > 1000万 + 无高风险，或 赛道溢价 × 互动质量 极高 |
| A | top 5%：商业价值 > $10万，或 粉丝 > 100万 + 赛道溢价中等以上 + 无高风险 |
| B | top 15%：商业价值 > $1万，或 有稳定变现能力 + 粉丝质量合格 |
| C | top 40%：有成长潜力，但暂未达到稳定变现 |
| D | top 70%：入门级，数据表现一般 |
| E/F | 存在风险信号（僵尸粉/断更/限流/数据造假） |

**关键原则**：评级反映"值多少钱、靠不靠谱"，不是"有多大"。50 万粉金融号可以拿 S，500 万粉僵尸号只能拿 D。

### 雷达图对标

评级看全局，雷达图看同级：评级定了之后，雷达图展示"在同级账号中，你的优势在哪、短板在哪"。

## 估值模型

### 5 大价值组件

| 组件 | 适用 | 计算逻辑 |
|------|------|----------|
| 品牌合作价值 | 全部 | 均播 × CPM × tier溢价 × 互动系数 × 地区系数 × 品牌加成 × 风险折损，市场基准夹紧 |
| 内容资产价值 | 全部 | 有效视频数 × 均播 × 内容CPM × 折现率 + 爆款加成 |
| 粉丝资产价值 | 全部 | 单价 × 真实粉丝^0.85 × 赛道系数 × 互动因子 × 风险折损 |
| 变现能力价值 | 全部 | 加权月收入 × 估值周期 × 增长乘数 × 风险折损 |
| IP/品牌溢价 | macro/mega | 粉丝 × 互动率 × 品类IP系数 × 层级IP率 × 品牌信号加成 |

### 核心参数

**粉丝资产幂律定价**（FOLLOWER_BASE_RATE）：
- nano: $0.005, micro: $0.01, mid: $0.05, macro: $0.5, mega: $12.0
- 幂律指数: 0.85

**互动因子**（tier-aware）：
- mega: high ≥ 1.5%, good ≥ 1.0%, normal ≥ 0.5%
- macro: high ≥ 3%, good ≥ 1.5%, normal ≥ 0.6%
- 其他 tier 逐级提高阈值

**IP/品牌资产率**（TIER_IP_RATE）：
- macro: 0.10, mega: 0.40

**估值周期**（VALUATION_PERIOD_BY_TIER）：
- nano: 4月, micro: 6月, mid: 12月, macro: 18月, mega: 24月

**维度权重**（按 tier 差异化）：
- mega: reach 16%, influence 20%, engagement 6%, content 6%
- nano: engagement 18%, content 15%, influence 3%

### 估值输出

每个组件输出清晰的"计算公式 + 市场对标 + 置信区间"，用户能看到完整的推理链。

## L1-L4 输出内容

### L1：估值概要（免费）

- 评级徽章 + 商业价值总额（中值 + 区间）
- 5 大组件三列卡片（品牌合作/粉丝资产/IP溢价 核心展示）
- 全量排名位置 + 赛道排名
- CTA 引导解锁完整报告

### L2：诊断结论（免费）

- 优势列表（3-5 条，含数据支撑）
- 关注点列表（2-3 条，含具体数据）
- 雷达图：vs 同级 S 级账号中位数
- 同侪排名表

### L3：收入增长（付费）

- 月收入估算（5 渠道拆分）
- 三情景 12 个月预测（保守/基准/乐观）
- 增长路线图（3/6/12 个月里程碑）
- 每条路线附具体行动建议

### L4：深度分析（付费）

- 同侪对比排名（多维度，含百分位）
- 品牌匹配推荐（按品类匹配度排序）
- 内容策略建议（内容支柱 + 最佳发布时间 + 推荐标签）
- 风险矩阵（概率 × 影响，含应对措施）
